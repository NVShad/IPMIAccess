# Changelog

Все заметные изменения этого проекта фиксируются здесь.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.1.0] - 2026-11-20

### Добавлено
- Переключение ввода клавиатуры между сервером и локальной ОС по `Ctrl+Shift+X`
  (и кнопкой «⌨ Ввод» в шапке); при отпускании захвата все зажатые клавиши
  отпускаются, чтобы модификаторы не «залипали».
- README на английском (`README.en.md`) и китайском (`README.zh-CN.md`)
  с переключателем языков.
- Раздел «Скриншоты» в README на трёх языках.
- Адрес BMC в заголовке страницы подставляется автоматически из `/api/status`.
- `config.example.bat` — шаблон настроек; реальные учётные данные в
  `config.bat` исключены из репозитория через `.gitignore`.

### Исправлено
- Смещение курсора мыши при масштабировании: масштаб мыши теперь
  синхронизируется с масштабом экрана (`autoscale`/`set_scale`), курсор
  попадает точно в цель при любом масштабе.

### Безопасность
- Из публикуемого кода удалены IP-адрес и учётные данные BMC; конфигурация
  задаётся только через переменные окружения.

## [1.0.0] - 2026-11-20

Первый публичный релиз.

### Добавлено
- KVM-консоль в браузере без Java: видеопоток ATEN iKVM (RFB, порт 5900)
  через локальный WebSocket→TCP мост; рендеринг — форк noVNC
  (kelleyk/noVNC, ветка `bmc-support`) с патчами под старые прошивки
  (24-байтный заголовок авторизации, родной 32-битный цвет AST2100).
- Панель датчиков в реальном времени: температуры, вентиляторы, напряжения,
  состояние корпуса; автообновление каждые 5 секунд, индикация порогов.
- Управление питанием: включение, корректное выключение (ACPI), reset,
  цикл питания, немедленное выключение.
- Системная информация: версия прошивки BMC, MAC/IP, ядро, статус питания.
- Масштабирование экрана: вписать в окно / 100% / 75% / 50% / 33%.
- Запуск в один клик через `IPMI-консоль.bat`.
- Получение одноразового KVM-токена из свежего JNLP перед каждым подключением.
- Проверено на Supermicro X7SB3 (прошивка IPMI 0135, ATEN iKVM V1.69.21).
